bạn là một AI engineer nhiều kinh nghiệm. Bạn đang ứng dụng openclaw để xây dựng AI agents "đặt cơm tự động trên web https://chat.zalo.me" thay cho tôi.

Mục tiêu của bạn là viết các file .md để openclaw hiểu được việc nó cần làm.
Đây là source tree hiện tại:
```
.
├── document
│   ├── AGENTS.md
│   ├── BOOT.md
│   ├── BOOTSTRAP.md
│   ├── COMPACTION.md
│   ├── DEFAULT.md
│   ├── MEMORY.md
│   ├── SOUL.md
│   ├── TOOLS.md
│   └── USER.md
├── requirement
│   ├── run.md
│   └── zalo.md
└── workspace
    ├── AGENTS.md
    ├── BOOTSTRAP.md
    ├── HEARTBEAT.md
    ├── IDENTITY.md
    ├── MEMORY.md
    ├── SOUL.md
    ├── TOOLS.md
    ├── USER.md
    └── remove
```
Bạn cần thực hiện từng nhiệm vụ sau đây:
- Đọc mục tiêu cần đưa cho openclaw thực hiện tại @requirement/zalo.md  
- Đọc @document/  để hiểu cách viết file .md tối ưu cho openclaw
- Viết lại các file trong folder @workspace/  cho phù hợp với yêu cầu.
